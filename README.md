### **🛠️ Troubleshooting & 기술 회고:**
문제1:정수와 실수 입력 시 발생하는 계산 오류
원인:반려동물의 몸무게나 운동시간을 입력받을 때, int()(정수)만 사용하면 소수점 데이터(예:5.5kg)를 입력했을 때 프로그램이 멈추는 현상이 발생함.
해결:사용자로부터 정밀한 수치를 입력받아야 하는 변수에는 float()함수를 사용하여 실수형 형변환을 수행함으로써 소수점 연산이 가능하도록 해결함.

문제2:복합 조건문(and/or) 설정 시 우선순위 혼동
원인:특별 칭호를 부여하기 위해 and연산자를 사용했는데, 조건식의 순서가 잘못되어 모든 반려동물에게 칭호가 부여되거나 혹은 아무도 부여받지 못하는 논리적 오류가 발생함.
해결:관계 연산자(>=)와 논리 연산자(and)의 우선순위를 고려하여,**'지수 180점 이상'**과 **'특정 활동량 충족'**이라는 두 조건이 모두 참(True)일 때만 실행되도록 조건식을 정교하게 수정함.

문제3: 가중치 연산 결과의 가독성 저하 
원인:가중치를 곱해 종합 건강 지수를 산출하니 결과값이 소수점 아래로 너무 길게 출력되어 리포트의 가독성이 떨어짐.
해결:파이썬의 f-string 포매팅 기술 중 하나인 {variable:.2f}문법을 활용하여, 최종 지수를 소수점 둘째 자리까지만 깔끔하게 표기하도록 개선함.

## 🟨 [3차 과제: V3.0] 무한 루프와 메뉴 시스템 (반복문) - 향후 작성 예정
### **✨3차 과제 업데이트 내용:**

  * 1. 핵심 업데이트 기능

메인 로직의 시각화: 메인 while문 내부를 함수 호출 위주로만 구성하여, 전체 프로그램의 흐름을 목차처럼 한눈에 파악할 수 있도록 간결화.

2. 변수 및 스코프(Scope) 관리
전역 변수(Global Variable) 활용: 반려동물의 이름, 나이, 체중, 활동 리스트를 프로그램 전체에서 공유할 수 있도록 전역 공간에 선언.

지역 변수(Local Variable) 및 global 키워드: 입력 함수 내에서 전역 변수의 데이터를 안전하게 업데이트하기 위해 global 키워드를 1회 이상 사용하고, 등급이나 칭호 등은 함수 내부의 지역 변수로 철저히 분리하여 메모리를 효율적으로 관리.
    
### **🤖 AI 파트너십 과정**
 1. 내용 1: 절차형 구조에서 함수 기반 모듈화 구조로의 개편

적용 내용: 기존에 순차적으로 실행되던 코드를 input_pet_data(), calculate_health(), print_health_report()라는 3개의 독립적인 함수로 분리함. 이를 통해 메인 while문 내부의 가독성을 높이고, 프로그램의 흐름을 목차처럼 직관적으로 파악할 수 있는 클린 코드를 구축함.

2. 내용 2: 변수 스코프(전역/지역 변수) 및 데이터 전달 메커니즘 정립

프롬프트 요약: "함수 간에 데이터를 주고받을 수 있도록 매개변수와 return 반환값을 활용해 주고, 프로그램 전체에서 쓰는 전역 변수와 함수 내부의 지역 변수 역할을 구분해서 global 키워드를 사용해 줘."

적용 내용: 프로그램 최상단에 전역 변수를 선언하고, 입력 함수 내부에서 이 데이터를 안전하게 갱신하기 위해 global 키워드를 적용함. 또한, 연산 함수에서 계산된 건강 지수 결과를 return문으로 반환받아 출력 함수의 매개변수(인자)로 넘겨주는 유기적인 데이터 흐름 체계를 완성함.
### **🛠️ Troubleshooting & 기술 회고:**
 1. 문제 1: 함수 내부에서 전역 변수 수정 시 값이 반영되지 않는 현상 (UnboundLocalError)

원인: 메인 메뉴에서 1번을 눌러 input_pet_data() 함수를 통해 반려동물의 이름과 나이를 새로 입력받았으나, 함수가 끝나고 메인 프로그램으로 돌아오면 기존에 설정해 둔 전역 변수의 초기값(빈 문자열)으로 자꾸 리셋되는 현상이 발생함. 파이썬에서는 함수 내부에서 전역 변수와 같은 이름의 변수에 값을 대입하면, 이를 전역 변수가 아닌 새로운 '지역 변수'로 취급해버리기 때문에 생긴 문제였음.

해결: 입력 함수 내부 최상단에 global pet_name, pet_age, pet_weight를 명시해 줌으로써, 파이썬에게 "이 변수들은 새로 만드는 게 아니라 바깥에 있는 전역 변수를 가져다 쓸 거야!"라고 선언하여 함수 종료 후에도 입력 데이터가 안전하게 유지되도록 해결함.

2. 문제 2: 함수 연산 결과가 다음 함수로 전달되지 않고 None이 출력되는 현상

원인: 건강 지수를 계산하는 calculate_health() 함수를 실행한 뒤 그 값을 print_health_report()에 넣었는데, 자꾸 점수가 0점이나 None으로 출력되는 논리적 오류가 발생함. 원인을 분석해 보니 계산 함수 내부에서 결과를 열심히 계산만 하고, 정작 메인 로직으로 그 값을 보내주는 return 문을 누락하여 함수가 아무것도 반환하지 않았기 때문이었음.

해결: 계산 함수 맨 마지막에 return index를 정확히 명시하여 연산된 결과값을 메인 프로그램으로 전달받았고, 이 반환값을 다시 출력 함수의 인자로 넘겨주는 올바른 데이터 파이프라인을 구축하여 해결함.
